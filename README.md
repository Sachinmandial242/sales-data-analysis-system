# Sales Data Analysis System

## Project Overview

The Sales Data Analysis System is a mini project developed using the R programming language. The main purpose of this project is to manage sales records and perform basic sales data analysis through a simple and user-friendly interface.

The application provides separate pages for adding sales records, viewing existing records, deleting selected records, and analyzing sales information.

## Objectives

- To develop a sales management application using R.
- To add and view sales records.
- To delete unwanted sales records.
- To perform basic sales data analysis.
- To understand the practical application of R programming.

## Features

- **Home Page:** Provides access to the different sections of the application.
- **Add Sales:** Allows users to enter new sales records.
- **View Sales:** Displays available sales information.
- **Delete Sales:** Removes selected sales records.
- **Sales Analysis:** Helps analyze the available sales data.
